# ROS AI Operating System (ROS AI OS)

## Version

0.1.0 Alpha

---

# Pengenalan

ROS AI OS ialah sistem AI yang dibangunkan untuk membantu proses penubuhan persatuan di Malaysia.

Sistem ini menggunakan Claude Projects sebagai AI Engine dan dibina secara modular menggunakan fail Markdown.

Matlamat utama projek ini ialah membimbing pengguna daripada peringkat idea sehingga dokumen penubuhan siap.

---

# Objektif

- Membimbing pengguna langkah demi langkah.
- Mengurangkan kesilapan semasa menyediakan dokumen.
- Menjana dokumen rasmi secara automatik.
- Menjadi AI Assistant khusus untuk penubuhan persatuan.
